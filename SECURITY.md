# Security policy

## Supported versions

During the beta, only the latest `0.x` beta release of each `@dixy-ui/*` package receives fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub: **Security → Report a vulnerability** on [akssmax/DixyUI](https://github.com/akssmax/DixyUI/security/advisories/new).

Include the affected package and version, a description, and steps or a minimal reproduction. You can expect an acknowledgement within 5 working days and a fix or mitigation plan within 30 days for confirmed issues. Reporters are credited in the advisory unless they prefer otherwise.
